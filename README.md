## 🎯 Overview

This repository showcases modern MLOps practices by combining powerful tools like DVC for data versioning and MLflow for experiment tracking. The project demonstrates end-to-end machine learning lifecycle management, from data preprocessing to model deployment.

---

## 🏗️ Project Structure

```
MLOps-DVC-MLFLOW/
├── data/                 # Data directory (tracked by DVC)
│   ├── raw/             # Raw, immutable data
│   ├── processed/       # Cleaned and preprocessed data
│   └── .gitignore       # Generated by DVC
├── models/              # Trained model artifacts
├── src/                 # Source code
│   ├── data/           # Data processing scripts
│   ├── features/       # Feature engineering
│   ├── models/         # Model training and evaluation
│   └── utils/          # Utility functions
├── notebooks/          # Jupyter notebooks for exploration
├── tests/              # Unit and integration tests
├── .dvc/               # DVC configuration
├── .github/            # GitHub Actions workflows
│   └── workflows/      # CI/CD pipelines
├── dvc.yaml            # DVC pipeline definition
├── dvc.lock            # DVC pipeline lock file
├── params.yaml         # Model hyperparameters
├── requirements.txt    # Python dependencies
├── MLproject           # MLflow project file
└── README.md          # This file
```

**Purpose**: CI/CD automation with GitHub Actions

**Features**:

**GitHub Actions Workflows**:
- `test.yml` - Run unit tests on pull requests
- `train.yml` - Trigger model training
- `deploy.yml` - Deploy models to production
- `dvc-repro.yml` - Reproduce DVC pipeline

**Workflow Example**:
```yaml
name: ML Pipeline
on: [push]
jobs:
  train:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python
        uses: actions/setup-python@v2
      - name: Install dependencies
        run: pip install -r requirements.txt
      - name: Run DVC pipeline
        run: dvc repro
      - name: Log to MLflow
        run: python src/models/train_model.py
```

**Setup Commands**:
```bash
git checkout cicd-pipeline
# GitHub Actions run automatically on push
# Check .github/workflows/ for configurations
```

## 🚀 Installation

### Prerequisites

- Python 3.8 or higher
- Git
- DVC
- pip or conda

### Setup Instructions

**1. Clone the repository**
```bash
git clone https://github.com/Ammar-Abdelhady-ai/MLOps-DVC-MLFLOW.git
cd MLOps-DVC-MLFLOW
```

**2. Create virtual environment**
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

**4. Initialize DVC**
```bash
dvc init
dvc remote add -d storage s3://your-bucket/path  # Configure your remote storage
```

**5. Pull data with DVC**
```bash
dvc pull
```

**6. Set up MLflow**
```bash
mlflow ui  # Starts MLflow UI on http://localhost:5000
```

## 📖 Usage

### Running the Complete Pipeline

**1. Reproduce DVC Pipeline**
```bash
dvc repro
```

**2. Train Model with MLflow Tracking**
```bash
python src/models/train_model.py --experiment-name "baseline-model"
```

**3. View Experiments in MLflow**
```bash
mlflow ui
# Navigate to http://localhost:5000
```

**4. Make Predictions**
```bash
python src/models/predict_model.py --input data/new_data.csv
```

### Working with Different Branches

```bash
# Switch to a specific branch
git checkout <branch-name>

# Install branch-specific dependencies
pip install -r requirements.txt

# Pull branch-specific data
dvc pull

# Run branch-specific scripts
# (Refer to each branch section above)
```

### Environment Variables

Create a `.env` file in the root directory:

```bash
MLFLOW_TRACKING_URI=http://localhost:5000
DVC_REMOTE=s3://your-bucket/path
AWS_ACCESS_KEY_ID=your_access_key
AWS_SECRET_ACCESS_KEY=your_secret_key
```

## 📦 Data Versioning with DVC

### Track new data
```bash
dvc add data/raw/new_dataset.csv
git add data/raw/new_dataset.csv.dvc .gitignore
git commit -m "Add new dataset"
dvc push
```

### Switch data versions
```bash
git checkout <commit-hash>
dvc checkout
```
